# Roadmap

0. Foundation: quality gates, architecture, models, ports, IndexedDB, security, documentation.
1. Characters: CRUD and avatars.
2. AI Providers: credentials, OpenAI-compatible/OpenRouter, models, streaming, cancellation, errors.
3. Conversations: persistence and context.
4. Personas: CRUD and attachment.
5. MVP polish: responsive accessible states, backup, offline/E2E validation, security review.

Future Memory: model/repository, UI, manual creation, opt-in extraction, retrieval limits, privacy/quality/prompt-injection assessment. Other future work: Character Cards, local models, worlds, group chats, voice, sync, self-hosting, desktop, mobile, sharing.
