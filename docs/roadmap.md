# Roadmap

GitHub [issues](https://github.com/mariepop13/livoa/issues) and [milestones](https://github.com/mariepop13/livoa/milestones) are the authoritative roadmap. This document is a public guide to the currently approved work; issue state, scope, and milestone assignment on GitHub take precedence.

## Current priorities

- **Core data safety:** [#79 — Complete backup coverage and versioned schema evolution](https://github.com/mariepop13/livoa/issues/79) is open. It is the unshipped Backup v2 correction for Character Card coverage, v1 import compatibility, atomic replacement, and safe memory-consent reset.
- **Advanced conversations:** [#76 — Persist conversation branches and active paths](https://github.com/mariepop13/livoa/issues/76) is open in the [Advanced conversations milestone](https://github.com/mariepop13/livoa/milestone/9).
- **Platforms & sync:** [#29 — Define an optional local-first synchronization contract](https://github.com/mariepop13/livoa/issues/29) is open in the [Platforms & sync milestone](https://github.com/mariepop13/livoa/milestone/8). Cloud synchronization is not currently shipped.
- **Provider expansion:** [#28 — Local model providers (deferred)](https://github.com/mariepop13/livoa/issues/28) is open in the [Provider expansion milestone](https://github.com/mariepop13/livoa/milestone/16). Local model providers are not currently shipped.

## Completed capabilities

Memory v1 is shipped: the model, local management UI, manual creation, opt-in extraction and bounded retrieval/context controls, and privacy/quality/prompt-injection assessment are complete. SillyTavern Character Card import and export is also shipped. These are completed capabilities, not future roadmap items.

The [Characters v2](https://github.com/mariepop13/livoa/milestone/10), [Worlds & lore](https://github.com/mariepop13/livoa/milestone/11), [Memory lifecycle & relevance](https://github.com/mariepop13/livoa/milestone/12), [Group conversations](https://github.com/mariepop13/livoa/milestone/13), [Voice](https://github.com/mariepop13/livoa/milestone/14), and [Sharing & discovery](https://github.com/mariepop13/livoa/milestone/15) milestones remain the tracker’s approved future areas. Consult their GitHub issues for any committed scope or sequence.
