# Livoa

Livoa is an open-source, local-first platform for creating and interacting with AI characters using the models and providers you choose.

The MVP requires no account and no Livoa backend. It stores characters, personas, conversations, messages, and settings locally by default.

## Development

Node.js 20.9+ is required. Install with `npm install`, then run `npm run lint`, `npm run typecheck`, `npm run test`, and `npm run build`.

See `docs/architecture.md`, `docs/security.md`, and `docs/roadmap.md`.
